# User Management System in C

A beginner-friendly **User Management System** developed in the C programming language. This project demonstrates the use of structures, arrays, functions, loops, and file handling to perform basic CRUD (Create, Read, Update, Delete) operations on user records.

## Features

* Add a new user
* View all users
* Search a user by ID
* Update user information
* Delete a user
* Save user data to a file
* Load existing user data automatically when the program starts
* Menu-driven console interface

## Technologies Used

* C Programming
* GCC Compiler
* Standard C Libraries (`stdio.h`, `stdlib.h`, `string.h`)

## How to Compile

Using GCC:

```bash
gcc user_management.c -o user_management
```

## How to Run

### Windows

```bash
user_management.exe
```

or

```bash
.\user_management.exe
```

### Linux / macOS

```bash
./user_management
```
