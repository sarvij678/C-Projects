# Digital Clock in C

A simple digital clock written in C that displays the current date and time.

## Features

- 12-hour format (AM/PM)
- 24-hour format
- Displays current date
- Updates every second
- Clears the screen for a live clock effect

## Technologies Used

- C
- time.h
- windows.h

## How to Compile and Run

Compile the program:

```bash
gcc clock.c -o clock
```

Run the program:

```bash
clock
```
